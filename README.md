# ⚡ AthletePro — Sports & Body Trainer

A complete, fully client-side training app — no build step, no server, works anywhere.

## 🌐 Live: hosted on GitHub Pages

## What's inside
- ⚽ **Football (33 plans)** — including Pro/Lamine-Yamal-tier ELITE & GRUEL sessions
- 🏏 **Cricket (15)** · 🏃 **Kho Kho (15)** · 🏀 **Basketball (15)**
- 🎯 **Speed & Agility (8)** · 🥊 **Cardio Combat (8)**
- 🏋️ **Gym / Full Body (20)** · 💪 **Abs & Core (15)** · 🏠 **Home Training (15)** · 🧘 **Warm-up & Recovery (8)**
- 🥗 **Diet Plan** with meals, calories, supplements
- 📘 **Exercise Guide** — 70+ step-by-step technique guides
- 🧮 **Body Tools** — 1RM, BMI, macro targets, weight tracker
- 📅 **Weekly Planner** · 📊 **Progress & Stats** with achievements
- ⭐ Favorites · 🎲 Surprise Me · 🔊 timer beeps · ⬇ export/import backup

## Run locally
Double-click `Start-Trainer.bat` (or `python -m http.server`).

## Tech
Vanilla HTML/CSS/JS — no frameworks, no dependencies. Data stored in `localStorage`.
